# AI-assisted development

LocalDex has been developed with assistance from OpenAI ChatGPT. Its assistance
has included suggestions and drafts for Python, JavaScript, HTML, CSS, Windows
launchers, documentation, tests, and some application imagery.

The project contributors have directed the product requirements, selected the
architecture, requested changes, integrated code and assets, and reviewed
results. **AI-assisted** does not mean every line was generated by AI, or that
all generated material has a single legal author.
